# IReckon Frontend

Vue3 现代前端界面

---

## 安装依赖

```bash
cd frontend
npm install
```

---

## 开发模式

```bash
npm run dev
```

然后访问 http://localhost:3000

---

## 构建

```bash
npm run build
```

---

## 功能

- 聊天界面 - 多层消息、实时 WebSocket
- 任务管理 - 创建、取消、恢复任务
- 仪表盘 - 系统状态、统计数据
- AI 实例管理 - 添加、编辑、删除、测试 AI 端点
- 设置 - 系统配置查看
- 深色/浅色主题切换
